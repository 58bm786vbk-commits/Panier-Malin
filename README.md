# Panier Malin — Prototype V0.2

Application web statique conçue pour fonctionner sans API, sans compte bancaire et sans serveur applicatif. Les données de démonstration sont sauvegardées localement dans le navigateur (`localStorage`).

## Publication sur GitHub Pages

1. Créez un compte sur [GitHub](https://github.com) si nécessaire.
2. Créez un nouveau dépôt public nommé, par exemple, `panier-malin`.
3. Importez tous les fichiers du dossier à la racine du dépôt, notamment `index.html`, `styles.css`, `app.js`, `manifest.webmanifest` et `.nojekyll`.
4. Dans le dépôt GitHub, ouvrez **Settings → Pages**.
5. Dans **Build and deployment**, sélectionnez **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)` ; enregistrez.
6. Après quelques minutes, GitHub affichera l’adresse publique, généralement `https://VOTRE-IDENTIFIANT.github.io/panier-malin/`.

Ouvrez cette adresse dans Safari sur l’iPhone. Pour l’utiliser comme une application : appuyez sur **Partager**, puis sur **Sur l’écran d’accueil**.

## Développement local

Sur un ordinateur, ouvrez simplement `index.html` dans un navigateur. Pour conserver les données de démonstration, utilisez toujours le même navigateur et la même adresse.
